# MiniZinc

This repository contains a Python parser for the [MiniZinc](https://www.minizinc.org) constraint modelling language, and the solver focussed subset [FlatZinc](https://docs.minizinc.dev/en/stable/flattening.html#). The sub-folders contain:

| Name | Content|
|------|--------|
|[minizinc](minizinc)|A Python MiniZinc parser |
|[flatzinc](flatzinc)|A Python FlatZinc parser|
