# Minesweeper

This folder contains a solution to the [Minesweeper](https://puzzlemadness.co.uk/minesweeper/) puzzle.

The model can be run from the IDE or from Python. The Python script accepts a simple text format and feeds to MiniZinc via the Python API. The model outputs a text format. Python outputs a PDF that presents the solution graphically.

For data file [minesweeper_6_9](data/minesweeper_6_9.dzn), the equivalent ASCII input is:
```
.24..11..
2...4.2.0
2.5.33.3.
.....2...
23...32..
..2...1.1
```
A digit indicates the number of bombs in the eight surrounding cells (less for cells at the edge of the grid). A `.` is unknown. The goal is to determine for each unknown cell, if it contains a bomb, and if not how many surrounding cells contain a bomb.

The ASCII output from MiniZinc is:
```
124*31100
2***4*210
2*5*33*31
123212*4*
23*22323*
**22**111
```
`*` indicates a bomb.

The PDF generated by Python is [minesweeper_6_9.pdf](data/minesweeper_6_9.pdf).

To run the Python variant:
```
python3 minesweeper.py data/minesweeper_6_9
```
The file is assumed to have a `.txt` extension. The output file is the same as the input but with extension `.pdf`. Alternately:
```
python3 minesweeper.py data/minesweeper_6_9 solution
```
puts the output in file `solution.pdf`.
