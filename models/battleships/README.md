# Battleships

This folder contains a solution to the solitaire version of the [Battleships](https://puzzlemadness.co.uk/battleships/) puzzle.

The model can be run from the IDE or from Python. The Python script accepts a simple text format and feeds to MiniZinc via the Python API. The model outputs a text format. Python outputs a PDF that presents the solution graphically.

For data file [battleships_7_7](battleships_7_7.dzn) the equivalent ASCII input is:
```
3 3 1

1 3 2 2 1 3 0
2 2 0 4 0 2 2

.......
.......
.x...x.
.x.....
.......
o......
.......
```
The interpretation is:
- `<` - leftmost cell of a horizontally oriented ship
- `>` - rightmost cell of a horizontally oriented ship
- `^` - top cell of a vertically oriented ship
- `v` - bottom cell of a vertically oriented ship
- `#` - interior cell of a ship
- `o` - ship consisting of a single cell
- `x` - cell that contains no ship
- `.` - unknown cell (goal is to determine content of such cells)

The ASCII output from MiniZinc is:
```
 ^     
 v ^  ^
   #  v
o  v   
     ^ 
o  o v 
       
```
In the output, cells with no ship are blank rather than `x`.

The PDF generated by Python is [battleships_7_7.pdf](data/battleships_7_7.pdf).

To run the Python variant:
```
python3 battleships.py data/battleships_7_7
```
The file is assumed to have a `.txt` extension. The output file is the same as the input but with extension `.pdf`. Alternately:
```
python3 battleships.py data/battleships_7_7 solution
```
puts the output in file `solution.pdf`.
